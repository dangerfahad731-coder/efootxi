# 安装、资源下载与更新

[下载 V1.4.0 正式版](https://github.com/maxlzyver/efootxi/releases/tag/v1.4.0)。最低要求 Android 9、64 位 ARM 设备，实际兼容情况以测试结果为准。安装后按页面提示选择补丁并完成资源准备，无需手动搬运或解压；完整资源准备后可离线游玩。
